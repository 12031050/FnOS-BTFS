# FnOS-BTFS
# 面向WEB3应用的下一代存储
什么是 BTFS ？

作为BitTorrent生态系统中的创新力量，BTFS不仅加速了分布式文件共享技术的发展，还在DePIN领域占据了领先地位。DePIN（去中心化物理基础设施网络）鼓励网络参与者通过代币奖励机制共同投入资源，部署和维护更稳定高效的网络基础设施。目前主流的公链大多侧重于计算任务，但缺乏经济高效、可扩展且高性能的文件存储和共享解决方案。

这正是BTFS旨在解决的问题。此外，BTFS依托BTTC，实现了跨链连接和多渠道支付，使其成为更便捷的选择。BTFS、BitTorrent和BTTC网络的整合将提升DApp开发者服务更广泛市场的效率。
